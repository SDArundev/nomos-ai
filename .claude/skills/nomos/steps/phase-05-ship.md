# Phase 5: SHIP

Git operations, PR creation, state transition. No agents — orchestrator handles directly.

**Input:** `.nomos/output/{feature_id}/cp-04.json`
**Output:** `.nomos/output/{feature_id}/cp-05.json`
**Context clearing:** After writing cp-05.json, all phase 5 context is discarded.

---

## 5.1 Read Checkpoint

Read `cp-04.json`. Extract:
- `env` (worktree_path, output_dir, project_root)
- `flags` (merge, cleanup)
- `feature_summary` (id, title, ac)
- `data.verdict` (must be PASS to proceed)

---

## 5.2 Commit Changes

```bash
cd {env.worktree_path}
git add -A
git reset HEAD -- .nomos/features.json 2>/dev/null || true
git status
```

If changes exist:
```bash
git commit -m "feat({feature_id}): {feature_summary.title}"
```

---

## 5.3 Push Branch

```bash
git push -u origin nomos/{feature_id}
```

---

## 5.4 Create Pull Request

```bash
gh pr create \
  --title "feat({feature_id}): {feature_summary.title}" \
  --body "$(cat <<'EOF'
## Summary
Implements {feature_summary.title} ({feature_id}).

## Acceptance Criteria
{feature_summary.ac — formatted with checkmarks}

## Verification
- Gate A (Static): PASS — typecheck, lint, tests
- Gate B (Review): PASS — code review, security review
- Gate C (Functional): PASS/SKIP

## Changes
{files_changed from cp-03}

---
_Generated by NOMOS v4 pipeline_
EOF
)"
```

Capture PR URL:
```bash
PR_URL=$(gh pr view --json url -q '.url')
PR_NUMBER=$(gh pr view --json number -q '.number')
```

---

## 5.5 Record PR URL

State is already `waiting_approval` (set by phase 4). Record the PR URL on the feature:

```bash
jq --arg id "{feature_id}" --arg url "$PR_URL" --arg ts "$(date -u +%Y-%m-%dT%H:%M:%SZ)" '
  .features |= map(if .id == $id then .prUrl = $url | .prCreatedAt = $ts else . end)
' {env.project_root}/.nomos/features.json > {env.project_root}/.nomos/features.json.tmp \
  && mv {env.project_root}/.nomos/features.json.tmp {env.project_root}/.nomos/features.json
```

---

## 5.6 Merge (if -m flag)

**IF flags.merge == true:**

```bash
cd {env.worktree_path}
git fetch origin main
git rebase origin/main
```

If conflicts: resolve or escalate.

Post-rebase validation:
```bash
bun run check-types && bun run check && bun run test:ci
```

If validation passes:
```bash
cd {env.project_root}
git checkout main
git merge --no-ff nomos/{feature_id} -m "merge: {feature_id} — {feature_summary.title}"
# Include current features.json state in the merge
git add .nomos/features.json
git commit --amend --no-edit
git push origin main
```

Update state:
```bash
bash .claude/skills/nomos/scripts/nomos.sh state verify {feature_id}
```

---

## 5.7 Cleanup

Release ports:
```bash
bash .claude/skills/nomos/scripts/nomos.sh ports release {feature_id}
```

**IF flags.cleanup == true:**
```bash
git worktree remove .nomos/worktrees/{feature_id} --force
git branch -d nomos/{feature_id}
```

Teardown tmux:
```bash
bash .claude/skills/nomos/scripts/tmux-session.sh teardown {feature_id}
```

---

## 5.8 Write cp-05.json

```json
{
  "v": 4,
  "phase": 5,
  "feature_id": "{feature_id}",
  "ts": "{ISO-8601}",
  "status": "completed",
  "env": {cp-04.env},
  "flags": {cp-04.flags},
  "feature_summary": {cp-04.feature_summary},
  "data": {
    "git_ops": {
      "branch": "nomos/{feature_id}",
      "commits": {N},
      "pushed": true,
      "pr_created": true,
      "pr_url": "{PR_URL}",
      "pr_number": {PR_NUMBER},
      "merge_commit": "{hash or null}"
    },
    "state_transition": "in_progress -> waiting_approval",
    "cleanup": {
      "ports_released": true,
      "worktree_removed": {flags.cleanup}
    }
  }
}
```
